# When Tasks Collide

An interactive React app that explains multitask learning: why task gradients conflict and how GradNorm, PCGrad, GradVac, CAGrad, MGDA and uncertainty weighting handle it.

## What's inside

- `src/App.tsx` is the app
- `src/components/` holds the interactive demos

## How to run

```bash
npm install
npm run dev
```
